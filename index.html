Webflow Data API v2 · CMS automation

Import content into Webflow CMS without surprises.

Paste a collection schema, your CSV, and what's already in the collection. The planner checks every row against the field types, matches items by slug, and shows exactly which batched API requests a sync would send. This playground runs entirely in your browser and needs no API token.

The schema has the same shape as GET /v2/collections/{id}. Existing items use the shape of GET /v2/collections/{id}/items → items.

Run it against your site

    
export WEBFLOW_TOKEN=…            # site token with CMS read/write scopes
node bin/webflow-cms-sync.mjs --collection <collectionId> --file case-studies.csv            # dry run
node bin/webflow-cms-sync.mjs --collection <collectionId> --file case-studies.csv --apply --publish

    
It's a dry run by default. Invalid rows never reach the API, and items that exist only in Webflow are reported but never deleted. On a 429 the CLI waits as long as Retry-After says, and it slows down when X-RateLimit-Remaining runs low.
